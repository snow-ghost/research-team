## Ограничения

Значения диаметра для `r=2…8` остаются вычислительными гипотезами, а не общими доказательствами. Теорема о flip для `n≥6` не доказывает диаметр компоненты. Абляция показывает необходимость Lean-проверки даже при правильном `outcome`; одна общая задача не оценивает устойчивую пользу навыков. Случай `r=8,n=15` завершён, но `r=6` по-прежнему не имеет общего доказательства `D=n−2`.
