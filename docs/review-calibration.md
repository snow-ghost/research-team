# Проверка качества рецензий

`research-review-calibration` выполняет отдельный ограниченный опыт: шесть
учебных случаев, два представления входа, два повторения, не более 24 запросов.
Два случая корректны, включая допустимое опровержение. Четыре содержат
несоответствие естественной постановки формальной цели: изменение заключения,
добавление предпосылки, замена связки или ограничение области.
Все предложенные формальные доказательства предварительно проверяются Lean.
Успех Lean не устраняет намеренное несоответствие текстовой постановке.

```sh
go run ./cmd/research-review-calibration \
  -server-config /private/server.json -profile reviewer \
  -out /private/new-calibration -confirm
```

Нужны доверенный профиль модели и закрепленная среда Lean. Создается новый
закрытый каталог; повторное использование каталога запрещено. Пределы одной
попытки: 32768 выходных токенов, 900 секунд, один шаг, без инструментов.
Запуск требует отдельного разрешения на передачу этих материалов поставщику.
Ключи и исходные пути не входят в логический пакет. Эталонные замечания
хранятся отдельно и не передаются рецензенту. Имена целей и заданий не обозначают
тип дефекта. Порядок двух представлений меняется во втором повторении.

Для каждого запроса сохраняются резервирование, вход, полный ответ, расход,
диагностика и результат разбора. Неизвестный удаленный исход или отсутствие
ответа останавливает опыт без автоматического повтора. Некорректный формат
рецензии учитывается отдельно от содержательной ошибки.

## Оценка замечаний

Число замечаний не является показателем качества. Проверяющий сопоставляет
каждое замечание с конкретным эталонным дефектом либо отмечает ложное замечание.
Файл разметки содержит `case`, `report_sha256`, `annotator`, а также `findings`
с `index` и необязательным `issue`. Пустой `issue` обозначает отсутствие
соответствия эталонному дефекту. Требуется полная разметка всех замечаний.

```sh
go run ./cmd/research-review-score -case changed_bound \
  -report /private/review.json -annotation /private/annotation.json
```

Подсчет проверяет контрольную сумму отчета и идентификаторы эталона. Выдаются
обнаруженные и пропущенные дефекты, ложные замечания, повторы, редакционные
замечания, точность и полнота, когда их знаменатели ненулевые.
Редакционное замечание не считается обнаружением математической ошибки.
Разметка моделью должна быть обозначена как разметка моделью, а не человеком.
Шесть учебных случаев не дают оценки качества на произвольных исследованиях.
