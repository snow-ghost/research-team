# Веб-макет исследовательской команды

Отдельный клиент на демонстрационных данных. Действующие агенты, языковые модели, Go-координатор и серверная база данных не подключены. Математическая приемка в интерфейсе изменяет только учебные записи.

## Запуск

Проверено с Node.js 24.20.0. Зависимости закреплены в `package-lock.json`.

```bash
cd web-research-demo
npm ci
npm run dev -- --port 4187 --strictPort
```

Адрес: <http://127.0.0.1:4187/>. Если порт занят, нужно выбрать другой свободный порт. Сервер привязан к локальному адресу; макет не предназначен для размещения в открытой сети.

## Возможности

- Два исследования, карта ветвей, граф зависимостей и списочное представление.
- Карточки постановки, условий, оснований и вопросов.
- Разбиение на два случая с отдельным обязательством покрытия.
- Леммы-кандидаты и предложение применения общей леммы в другой гипотезе.
- Запись задания поиска контрпримера без запуска вычисления.
- Демонстрационная рецензия, замечания, запрос перепроверки и оспаривание основания.
- Три последовательных события учебного сценария.
- История со снимками только для чтения, сохранение в браузере и выгрузка JSON.
- На телефоне по умолчанию открывается список; схема доступна переключением.

Вопрос получает сведения из полей выбранного объекта с версией снимка. Это не генеративный ответ и не сообщение действующего агента.

Леммы и примеры относятся к конечным графам. Состояния работы вымышлены и не относятся к реальным исследованиям.

## Ограничения

Новые пользовательские леммы остаются кандидатами. Автор не принимает свой результат. Применение леммы создает обязательство, а не автоматически доказанное заключение. Приемка применения в демонстрационном сценарии предусмотрена только для L2 и H3; общий проверяющий не реализован.

Материалы сохраняются под ключом `research-team-demo-v1` в localStorage для данного адреса. История находится только в браузере. При очистке данных браузера она теряется; предусмотрена выгрузка выбранного снимка с предшествующей историей. При исчерпании места появляется предупреждение. Секретные данные в макет вводить не следует.

Нет авторизации, настоящего управления процессами, потока серверных событий, импорта сохраненного JSON или редактора полного доказательства. Пауза относится только к демонстрационному сценарию.

## Проверки

```bash
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Браузерные проверки сами запускают сервер на 4187 и используют Chromium из установки Playwright. Для готового экземпляра задается `DEMO_URL`, для другого установленного браузера задается `CHROME_PATH`. На Linux может потребоваться `npx playwright install --with-deps chromium`. В GitHub Actions повторное использование уже работающего сервера запрещено.

15 проверок модели охватывают разбиение, отдельную приемку, контрпримеры, повторное использование, оспаривание, вопросы, неизменность принятой версии и исторические снимки.

10 браузерных сценариев охватывают карту и стрелки, вопросы после перезагрузки, разбиение, применение леммы, замечания, исторический режим, сценарий, выгрузку, телефон и длинный заголовок на экране шириной 320 пикселей. Для маршрутов связей проверяются обход посторонних узлов, попадание в границу цели и направление последнего участка.

Изображения текущего прогона создаются в `test-results/`. Проверки интерфейса не являются проверкой новых математических доказательств.

## Устройство

- `src/model.js`: начальные данные, переходы и действительность зависимостей.
- `src/main.jsx`: экраны, граф, формы и обсуждение.
- `src/style.css`: настольное и узкое представления.
- `tests/model.test.js`: проверки предметных ограничений макета.
- `tests/browser/workflows.spec.js`: браузерные сценарии.
- `playwright.config.js`: проверочная среда.

Граф отображается React Flow; расположение вычисляет elkjs. Зависимости устанавливаются локально, внешние службы приложению не нужны. При недоступности алгоритма предусмотрено резервное расположение, которое не заменяет основную проверенную раскладку.

Производственная сборка включает крупную библиотеку расположения графов. Оптимизация загрузки и испытания больших графов не проводились. Текущий сборщик также предупреждает о директивах `use client` в зависимостях; макет полностью клиентский и не использует серверное выполнение React.
