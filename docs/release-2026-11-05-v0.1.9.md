# Релиз v0.1.9

## Серверный native-first

- При `lean_config` серверные `proof` и `formalize` сначала проверяют библиотечные применения и шесть нативных тактик, затем вызывают модель только после неуспеха. `native_first: false` отключает поведение.
- `library_search` передаёт `MatchReport.Source`, binders и подстановки без потери имён переменных. Каждый кандидат повторно проходит pinned checker.
- Результат `native` содержит число попыток, `library_applications`, отчёт и признак `model_fallback`. Успешные нативные кандидаты имеют нулевой model usage.
- `decide` раскрывает внешнюю цель и исходные определения без общего `intros`.
