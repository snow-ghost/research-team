# Веб-интерфейс исследовательской команды

Основной режим подключен к Go-серверу по `/api`. Он хранит исследования на сервере и управляет настроенными исполнителями. Учебный режим `?demo=1` использует отдельное состояние браузера и не обращается к агентам.

## Запуск

Нужны Node.js 24, Go 1.26 и Linux. Команды из корня репозитория:

```sh
cd web-research-demo
npm ci
npm run build
cd ..
./scripts/run-postgres.sh
```

Перед первым запуском подготовьте PostgreSQL по [инструкции Compose](../docs/postgres.md#запуск). Вариант без PostgreSQL: `go run ./cmd/research-server -config examples/server/local.json`.

Адрес: <http://127.0.0.1:4187/>. Для входа нужен ключ из файла, путь к которому сообщает сервер. При занятом порте измените `listen` в конфигурации. Настройки профилей, состояние, ограничения и API описаны в [инструкции сервера](../internal/researchweb/README.md).

## Рабочий Режим

- Создание исследований и лемм с явной постановкой и предпосылками.
- Карта зависимостей и разбиение на два случая с отдельным обязательством покрытия.
- Задания поиска доказательства, контрпримера, рецензии и ответа на вопрос.
- Выбор профиля и каталога материалов из серверных списков; подтверждение запуска и остановка попытки.
- Ограниченный цикл по дереву обязательств: число попыток, ожидание приемки, пауза, продолжение и остановка.
- Просмотр результата и расхода токенов, передача кандидата на приемку, запись обоснования решения.
- Применение принятой леммы через отдельное обязательство; контроль версий зависимостей.
- Замечания, оспаривание, перепроверка, исторические снимки только для чтения.
- Coddy: подготовка задания, публикация в GitHub, наблюдение, подтверждение плана, ответ, рецензия к строкам, сверка исхода и получение материалов.

Основное состояние опрашивается каждые две секунды. Локальная запись Coddy обновляется каждые десять секунд; обращение к GitHub требует команды оператора. Потока промежуточных сообщений модели пока нет. Вопрос создает задание, ответ появляется после запуска исполнителя.

Приемка представляет решение единственного оператора. Сервер проверяет наличие материала, его происхождение, версии и состояние зависимостей. Математическую корректность программа не устанавливает.

На узком экране карта по умолчанию заменяется списком; схему можно открыть переключателем. React Flow отображает граф, elkjs рассчитывает расположение. Большие графы и производственная нагрузка пока не испытаны.

## Учебный Режим

`?demo=1` содержит два вымышленных исследования конечных графов. Сценарий, ответы и приемка изменяют только учебные записи. Состояние сохраняется в `localStorage` под ключом `research-team-demo-v1`. Его очистка удаляет историю; доступна выгрузка JSON. Импорт не реализован. Секретные материалы в этот режим вводить не следует.

Для отдельной разработки учебного интерфейса:

```sh
cd web-research-demo
npm run dev -- --port 4187 --strictPort
```

Открывайте <http://127.0.0.1:4187/?demo=1>. Этот сервер Vite не предоставляет Go API.

## Проверки

```sh
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
npm run test:mvp
```

`test:e2e` запускает учебный сервер на 4187; `test:mvp` собирает Go-сервер и запускает его на 4190 с местными подстановками внешних служб. По умолчанию база временная SQLite; `MVP_DATABASE_URL` подключает отдельную пустую PostgreSQL с окончанием имени `_test`. Порты должны быть свободны. Реальные модели, Coddy Bot и исследовательские репозитории GitHub в этих испытаниях не используются.

`CHROME_PATH` задает путь установленного браузера. `DEMO_URL` применим только к учебной группе. Изображения прогона находятся в `test-results/` и не включаются в репозиторий.

Проверки охватывают предметные переходы, связи и стрелки, формы, исторический режим, узкий экран, запуск через Go API, отдельную приемку и процесс Coddy. Границы тестового покрытия не включают математическую правильность новых доказательств.

## Исходные Файлы

| Файл | Назначение |
|---|---|
| `src/main.jsx` | Общие экраны и формы |
| `src/connected.jsx`, `src/api.js` | Вход, HTTP-запросы и обновление состояния |
| `src/runtime.jsx` | Профили, задания, попытки и результаты |
| `src/cycles.jsx` | Разрешение и управление исследовательским циклом |
| `src/coddy.jsx` | Команды Coddy и материалы |
| `src/model.js` | Учебные данные, переходы, действительность зависимостей |
| `tests/mvp/` | Проверки через действующий Go-сервер |
| `tests/fixtures/mvp-server.mjs` | Временная проверочная среда |

Сборка включает крупную библиотеку расположения графов и предупреждает о директивах `use client` в зависимостях. Интерфейс выполняется в браузере; серверное выполнение React не применяется.
