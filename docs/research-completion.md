# Завершение исследования и происхождение исходников

`GET /api/studies/{id}/completion` возвращает состояние основной цели, число действующих попыток, готовых результатов, исходников исполнителей, представленных файлов, перенесенных исходников и заметок оператора. Бюджет содержит отдельные значения известных расходов, резервов и неизвестного расхода.

Состояние `completed` требует принятой основной цели с действительными основаниями либо принятого опровержения. Готовый результат `ready` отображается как `awaiting_operator`. Проверка Lean и рецензия не выполняют приемку автоматически.

При закрытии основной цели исследовательские задания этого исследования останавливаются. Неначатые попытки получают отмену без обращения к модели. Для выполняющихся попыток сначала сохраняется запрос остановки, затем координатор отменяет местный процесс. Отмена запроса не удостоверяет отмену вычислений у поставщика; неизвестный исход и резерв сохраняются. Поздний ответ удаленного исполнителя не заменяет сохраненное решение.

Завершенные ответы, исходники и журналы остаются неизмененными. Новые доказательные задания для дочерних целей закрытого исследования отклоняются. Ответы на вопросы оператора допускаются отдельно, с обычным подтверждением расходов. Другие исследования продолжают работать по собственным ограничениям.

Счетчики происхождения не устанавливают самостоятельность исследования. Представленная формализация задачи, инструкции, заметки оператора и исходники имеют разные роли. Нулевое число заметок не доказывает отсутствие любых внешних подсказок. Для оценки самостоятельности требуется разбор журнала и первоначальных материалов.
