# Релиз v0.1.8

## Native-first

- Добавлен `research-native`: фиксированный Lean-кандидат или пять нативных тактик проходят через pinned `leancheck.DockerChecker` без модели. Результат содержит отчёт `verification` и нулевой model usage.
- `Research202` и `Research209` прошли kernel verification с нулём вызовов.
- Новая `Research220` проверяет длину макроса при `n → n+1`. Пять нативных тактик не решили её, но эталонный кандидат через `sixUniqueFarOps_length` прошёл Lean с нулём вызовов. Четыре модельных профиля использовали 8 обращений, 3523 входных и 1316 выходных токенов; ни один не дал Lean-результата.

## Бюджет и сертификаты

- `research-compare` поддерживает `max_model_requests` для версий 2–4. Перед режимом резервируются шесть обращений; нехватка лимита создаёт `not_started_budget` без вызова. Нативный `lean` продолжается, а неполные группы исключаются из парного анализа.
- `-validate-only` показывает эффективный лимит. `-resume` требует неизменной конфигурации бюджета.
- Независимый Python BFS подтвердил число состояний, диаметр, flip и минимальность для `r=6,n=10,11,12`, совпав с C++.
- Индуктивный поиск `r=8` включён в регулярный artifact CI.
